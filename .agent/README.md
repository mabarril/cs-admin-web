# Documentação do Agente

Este diretório contém toda a documentação e artefatos gerados pelo agente de IA durante o desenvolvimento do projeto.

## Estrutura

### `/brain`
Contém os artefatos de planejamento, implementação e verificação:
- **task.md** - Lista de tarefas e progresso do desenvolvimento
- **implementation_plan.md** - Planos de implementação detalhados
- **walkthrough.md** - Documentação de mudanças e verificações realizadas
- Outros artefatos específicos de cada fase do desenvolvimento

### `/workflows`
Contém workflows reutilizáveis para tarefas comuns do projeto (deploy, testes, etc.)

## Propósito

Estes artefatos servem para:
- 📋 Manter histórico de decisões técnicas
- 🎯 Rastrear progresso e tarefas
- 📚 Documentar arquitetura e implementações
- 🔄 Facilitar onboarding de novos desenvolvedores
- 🤖 Fornecer contexto para futuras interações com o agente

## Versionamento

Todos os artefatos são versionados junto com o código para manter a rastreabilidade completa do desenvolvimento.
